PRODUCT PICTURES
================
Put product photos in this folder. No database change is needed.

File names (jpg / jpeg / png / webp):
    <inv_id>.jpg          e.g.  123.jpg        (best - never changes)
    <product-name>.jpg    e.g.  chicken-sandwich.png

Reference cake designs (shown on the Cake Order screen):
    reference/any-name.jpg

If a product has no photo here, the screens show a clean emoji tile instead.
